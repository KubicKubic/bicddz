# V5 参数形态、当前利用程度与下一步 scaling

## 结论

建议下一版先将状态 FFN 从 1536 缩到 1024，再在同样约 5M 的预算下将**状态宽度从 192 增至 224，历史宽度保留 192**。保留 3 层完整历史注意力、4 层状态处理、当前牌局全部事件、时序和精确的主体/条件带牌动作树。按现有模块公式，这个候选为 **5,053,424 参数**。

当前权重和功能诊断支持这种参数重分配；模型实际棋力和重新训练后的参数效率需要匹配对照确认。

## 审计对象与方法

- 审计冻结于 raw **48300 / global 74854**，共 **5,097,200 参数**。训练和上线模型未修改。
- 初始参照为 V5 `policy_0000000.msgpack`：它已继承训练好的 V4，并非随机初始化。新增残差输出从零开始，因此其 `delta/current=1` 本身没有重要性含义。
- 统计参数分布、权重 RMS、相对初始变化、EMA 差异、Adam 二阶矩、矩阵奇异谱、注意力头 QK/VO 变换相似性。
- 对 96 个角色/历史分层的真实训练状态做 CPU FP32 标准注意力诊断。只通过 `env.observe` 输入可见信息。三个角色与叫分阶段均覆盖，最长历史为 68；没有 >88 事件的样本。
- FFN 使用“激活 RMS × 输出权重范数”的平方作为单元影响代理；这不是实际输出方差分解。
- 分别置零模块残差输出，检查主体 KL、完整 greedy 动作变化、首次带牌条件 KL、自身 value 差异。首次带牌 KL 不包含后续带牌，不等于完整动作 KL。
- 三个 FFN 裁剪探针固定原模型形状，只屏蔽输出权重范数较小的神经元。它们验证直接裁剪的函数变化，不测真实缩小模型的吞吐，也没有蒸馏或续训。

详尽结果见 [JSON](V5_PARAMETER_EFFICIENCY_20261006.json)，图见 [PNG](V5_PARAMETER_EFFICIENCY_20261006.png)。输入状态和矩阵 CSV 留在 `runs/parameter_efficiency_v5_20261006_v1/`，不发布训练状态中的私有手牌。

## 参数分布

| 模块 | 参数 | 占比 |
|---|---:|---:|
| 四组状态 FFN | 2,367,744 | 46.45% |
| 状态 self/cross attention 与对应 norm | 1,188,864 | 23.32% |
| 三组历史 FFN | 593,088 | 11.64% |
| 历史 self attention 与对应 norm | 445,824 | 8.75% |
| Actor/critic MLP 与输出 | 283,231 | 5.56% |
| 动作集合、主体交互、条件带牌 | 144,913 | 2.84% |
| 历史输入与时序嵌入 | 56,064 | 1.10% |

FFN 合计 **58.08%**，是压缩预算的主要来源。参数成本与计算成本不同：历史 FFN 在最多 193 个含 null 的 token 上运行，状态 FFN 只处理 16 个 token；历史模块的计算占比可以明显高于其参数占比。

## 当前利用程度较高的部分

### 最早的历史读取与前三层状态交互

| 置零的模块 | 模块参数预算 | 主体 KL | 完整动作变化 |
|---|---:|---:|---:|
| `cross0` | 148,224 | 9.2532 | 42/96 |
| `self0` | 148,224 | 2.5994 | 19/96 |
| `self1` | 148,224 | 1.7528 | 20/96 |
| `self2` | 148,224 | 2.1522 | 17/96 |
| `memory_self0` | 148,224 | 1.8993 | 20/96 |
| `ff0` | 591,552 | 4.4079 | 39/96 |

这些通路已经承担很强的信息利用和决策功能。特别是 `self1` 置零还造成首次带牌条件 KL 4.1838，不能只看主体选择。

### 小而有效的合法动作语义查询

`prefix_keys/query/context` 共 **21,840 参数**。分别去掉 query/context，主体 KL 为 **0.4378 / 0.4874**，完整动作改变 **5/96 / 7/96**。`prefix_wing` 仅 **1,056 参数**，首次带牌条件 KL 达 **0.3240**。这些结果提示语义共享的动作表示值得保留，参数成本很小。

## 当前利用程度较低、适合优先做压缩对照的部分

### 状态 FFN 扩宽的边际利用较低

每层 1536 个神经元，覆盖 90% 影响代理所需单元数为：

| FFN | 90% 代理覆盖所需单元 | 从 V4 扩展的后 896 单元所占代理分数 |
|---|---:|---:|
| `ff0` | 393 | 1.26% |
| `ff1` | 580 | 8.66% |
| `ff2` | 471 | 6.27% |
| `ff3` | 1099 | 58.10% |

`ff3` 是整层新增的通路；用 640 作为分界只便于比较，不能将它前 640 个单元称为继承单元。它的单元使用较分散，但整体残差对输出影响较小。故“层内单元活跃”与“整层边际贡献大”不能混为一谈。

直接裁剪四层状态 FFN 的结果：

| 每层保留单元 | 物理缩小后的参数预算 | 主体 KL | 完整动作变化 | 自身 value RMS 变化 |
|---|---:|---:|---:|---:|
| 1536，原模型 | 5,097,200 | 0 | 0/96 | 0 |
| 1024 | **4,308,720** | **0.0395** | **1/96** | 0.511 |
| 768 | 3,914,480 | 0.0811 | 2/96 | 0.585 |
| 512 | 3,520,240 | 1.6564 | 16/96 | 1.610 |

1024 是优先验证的温和方案，可省 **788,480 参数，15.47%**。512 的直接损伤明显增大。96 个局面上的动作一致性不能证明棋力保持；value 变化也必须通过 own-seat GAE 的 explained variance 和校准复查。

### 后层与新增动作评分通路

- `cross3`：主体 KL **0.00123**，动作 **0/96** 改变，但自身 value RMS 变化 **0.795**。
- `self3`：主体 KL **0.02338**，动作 **2/96** 改变。
- `memory_ff1/2`：主体 KL **0.01096 / 0.03093**，动作 **1/96 / 3/96** 改变。
- `memory_self2`：主体 KL **0.02469**，动作 **1/96** 改变。
- 显式主体到牌点的候选评分输出被关掉后：主体 KL **0.000664**，动作 **0/96** 改变。这条评分分支涉及约 **53,217 参数**，其中一些牌点/主体特征还被带牌/value 使用。不能把整个分支的成本只算成输出门的 97 参数，也不能认为这些共享特征均可删除。
- 自由 `body_wing_factors` 表有 **4,944 参数**，置零首次带牌条件 KL 仅 **0.00000528**，其约 71% 坐标的当前 Adam 二阶矩为零。语义 `prefix_wing` 当前承担更多带牌偏好。

新增注意力/FFN 输出已明显学成非零，EMA 仍在变化。后层当前影响较小可能包含暖启动造成的路径依赖；没有证据证明它们在重新训练后仍然无用。保留 3/4 层深度，先减宽；不依据这份样本删掉完整历史注意力。

## 奇异谱与未使用参数的解释

- 状态 FFN 核的 99% Frobenius 能量秩约 **174–186**，接近 192。这提示完整状态维度被使用，不能把神经元扩宽的冗余理解为主干维度整体无用；也不能据此宣称 192 已成为能力瓶颈。
- 多数注意力 192×192 投影的 99% 能量秩约 **122–147**。普通低秩分解需要 `r < 96` 才能节省参数，因为 `192r + r192 < 192²`。因此单纯按奇异谱截断到“99% 保留”并不能得到更小的注意力投影。
- FFN 本身是非线性的。权重秩与实际激活/输出误差不同，应使用局面校准和蒸馏，不能直接合并两层为一个低秩线性映射。激活感知的压缩思路可参考 [SVD-LLM](https://arxiv.org/abs/2403.07378)，其论文结果来自语言模型，斗地主收益需要另测。
- `memory_position` 的 90%/99% 能量秩为 **8/51**，可以研究低秩位置基底或相对时序。全表只有 36,864 参数，节省规模有限；必须保留时序、192 事件容量和变长支持。
- 当前完整动作策略不访问微步 pending 输入：rank 的最后两个通道恒为零，部分 context 字段/类别恒定，可删除并将常量折叠进 bias。若重新使用微步策略则此结论失效。保留角色、所有可见公共信息、每次 play/pass 和底牌信息。
- 零 Adam 二阶矩不等于永久无用：不合法动作、未使用微步通道有结构性原因；很晚的历史位置与罕见动作也可能只是近期没有样本，或二阶矩下溢。尤其不能因位置表当前约 44% 二阶矩为零就截断历史。
- 各注意力头的 VO 变换最大相似性通常较低；没有直接证据支持全面合并注意力头。参数量目前也不大，优先 FFN。

## Scaling 方案与参数预算

下列预算来自现有算子结构公式；不是已训练的新版本。状态/历史独立宽度和逐层 FFN 需要实现新架构。

| 候选 | 状态宽度 | 历史宽度 | 状态 FFN | 历史 FFN | 参数 |
|---|---:|---:|---|---|---:|
| 当前控制 | 192 | 192 | 1536×4 | 512×3 | 5,097,200 |
| 温和压缩 | 192 | 192 | 1024×4 | 512×3 | **4,308,720** |
| 首选，同等预算重分配 | **224** | **192** | **1024×4** | **512×3** | **5,053,424** |
| 下一档扩容 | 256 | 192 | 1024×4 | 512×3 | **5,859,568** |
| 分层压缩候选 | 192 | 192 | 1024/1024/1024/512 | 512/256/256 | 3,914,480 |
| 吞吐优先的窄历史候选 | 192 | 128 | 1024×4 | 256×3 | 3,550,256 |

首选 224 状态宽度可以使用 7×32 个状态注意力通道，历史保持 6×32；256 使用 8×32。扩大短状态序列的交互宽度，同时保持历史编码宽度与完整事件数，避免同时扩大所有历史 token 的计算。实际速度仍须比较 GPU GEMM/cuDNN 的实现效率。

实施顺序：

1. **先验证 4.31M 压缩模型。** 物理裁剪 incoming/outgoing/bias 对应单元，使用独立校准局面选择单元；拷贝保留坐标的 Adam 状态。对完整动作分布和自己的 value 蒸馏，再恢复相同 PPO。单步 argmax 一致性只作迁移诊断。
2. **做同预算 5.05M 结构重分配。** 比较状态 224、历史 192、FFN 1024 与当前 5.10M 控制。LayerNorm/注意力宽度变化不能仅靠补零声称保函数；需校准/蒸馏迁移。
3. **只有新分配胜出后才跑 5.86M。** 保留历史宽度 192，将新增参数放在状态 self attention、历史查询和相应状态通道。
4. **SwiGLU 做单独匹配对照。** 按三个投影的成本选约 672/704 隐藏单元，与 GELU 1024 的两个投影匹配预算，不直接使用相同隐藏宽度。参考 [GLU Variants Improve Transformer](https://arxiv.org/abs/2002.05202)；论文的语言建模改善不保证本任务收益。
5. **窄历史与逐层不等宽随后验证。** 先补足 >88 的真实牌局诊断与评测，检查历史信息保留和 value。不要同时改时序、历史宽度、动作头和 PPO 协议。

所有方案保留完整当前牌局事件、变长时序、全注意力、地主/下家/门板角色、压牌合法性与单次完整出牌决策。动作空间继续使用精确主体/条件带牌表示。暂不扩宽当前利用较低的候选评分分支；先核对其与 direct actor、合法集合查询的功能重叠和计算开销。

## 验证参数效率的标准

同一冻结起点、同一 seed/对手池/PPO 设置：gamma=1、lambda=.95、lr=1e-5、own-seat GAE、自适应 vf、1 epoch、EMA=.999 每 rollout 一次。八卡实验通过现有 FIFO 调度，不修改当前训练的冻结依赖。

分别比较固定**新决策数**和固定**总 GPU 时间**，不只比较 update 编号。记录每秒新决策、完整 round 时间、峰值显存、KL/clip、角色分解 value explained variance。

能力验收使用原有 DouZero best 三角色等权期望分数及共同牌局配对置信区间，同时对多个较早版本验证；共同牌中的六条角色/控制腿按一副牌作为 bootstrap 单位，不把反复使用的同一副牌算作新增独立样本。先固定非劣界，例如平均归一化期望分下降不超过 0.01，再比较吞吐和强度的 Pareto 前沿。

PPO 自对弈数据会随策略变化；不能把语言模型的 tokens/parameter 常数直接移植。这里通过同样样本量与算力的少量固定对照寻找实际 scaling 方向，参照 [compute-optimal training](https://arxiv.org/abs/2203.15556) 的实验思路，不采用其语言模型数值结论。
