## 迁移与工程证据

29 个针对性测试通过，另有 3 个 V5 兼容性检查通过。覆盖新增注意力梯度、
FP32/BF16、0/2/89/192 长度历史、padding、时序、PPO rollout/update、
旧 Adam moments、多个代际的坐标年龄、EMA、checkpoint 恢复和架构热更新。

完整模型从 raw 49600 / global 76154 检查 96 个按角色/历史分层的真实局面。
实测历史最长 68；更长历史使用单独合成工程测试，不能当作真实对局验证。
raw 和 EMA 的 FP32 logits、完整动作 logprob 与 value 均完全一致。
CPU BF16 编译图仍有数值差异：raw 平均 body KL 0.000216，EMA 0.000889；
两者均 0/96 完整贪心动作变化。最大 body KL 分别为 0.007017、0.056938，
最大 value 差分别为 0.223389、0.264048。BF16 不宣称逐位等价。
后台 CPU Serving 前向中位数约 40.6 ms。

最初直接扩充 DenseGeneral 头轴的方案在完整 BF16 核验中暴露偏移，已用
独立头组取代；完整 FP32 证明保留数学函数，BF16 误差单列报告。
晋级还要求远程真实 cuDNN BF16 检查：平均 KL < 0.003、贪心差异率 ≤ 2%，
以及 value/logprob 和有限值检查。CPU 数值结果不替代 CUDA 验收。
